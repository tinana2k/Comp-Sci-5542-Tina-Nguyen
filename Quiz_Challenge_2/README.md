## 📌 Project Overview  
This project builds a **Speech Intelligence System** using pretrained foundation models. The system takes an audio input (lecture or meeting), converts speech to text, and generates useful insights such as summary, action items, sentiment, and keywords.

The goal is to demonstrate how AI can transform raw audio into meaningful and actionable information.

---

## 🚀 Features  
- Speech-to-text transcription using OpenAI Whisper  
- Automatic summary generation  
- Action item extraction  
- Sentiment analysis  
- Keyword extraction  
- Baseline vs Improved prompt comparison  

---

## 🧠 Models Used  
- OpenAI Whisper – Speech recognition (audio → text)  
- (Optional) LLM for summarization, sentiment, and keyword extraction
